# Thesis Data Visualizations

This small project contains Jupyter Notebook visualizations for a dataset of AI incidents (sourced from the AIAAIC repository). The main notebook (drawer.ipynb) demonstrates basic data cleaning and plotting: it groups incidents by year to produce a time series of incident counts and creates pie charts showing incident types and targeted groups.

Files included:
- drawer.ipynb — notebook with data processing and visualizations
- requirements.txt — minimal Python dependencies

Quick start:
1. Install dependencies: `pip install -r requirements.txt`
2. Open the notebook with Jupyter Lab or Notebook and run the cells to reproduce the charts.

Feel free to extend the analyses, improve the visual style, or add interactive plots.
